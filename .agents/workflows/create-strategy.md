# 新交易策略开发与接入工作流 (Create Strategy)

当需要开发一个全新的量化交易策略并接入系统时，遵循以下开发流程：

## 步骤 1：创建策略文件
1. 在 `src/service/` 或 `src/strategy/` 下新建策略文件。
2. **第一行必须声明**：`# coding=gbk`，并使用 GBK 编码保存。

## 步骤 2：实现策略三要素
1. **行情订阅与指标计算**：
   - 编写 `on_quote` 回调，提取最新价格与指标特征。
2. **交易信号与开平仓决策**：
   - 增加防重复下单判断条件与风控检查。
3. **委托下单与回报跟踪**：
   - 调用 `xt_trader.order_stock`（买入量满足 100 股整数倍，价格四舍五入 2 位小数）。
   - 在回调类中实现 `on_stock_order` 与 `on_stock_trade` 状态同步。

## 步骤 3：本地编译与静态校验
执行编译检查确保无编码冲突：
```bash
python -m py_compile <新策略文件路径>
```
